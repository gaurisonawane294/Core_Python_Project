This is  Online Course Management System  to manage online courses, student registrations, course enrollments, and admin records. The system provides two panels: Admin Panel and Student Panel, allowing administrators and students to perform their respective operations easily.

The Admin Panel allows the administrator to add new courses, view available courses, update course details, delete courses, view registered students, manage enrollments, and check payment details.

The Student Panel allows students to register by providing their name, email, password, and mobile number. After successful registration, students can log in using their credentials. Students can view available courses, enroll in selected courses, check their enrolled courses, and view payment details. The system provides two payment options: Pay Now and Pay Later, with payment status maintained as Paid or Pending.

The project uses Python for application development, MySQL for database management, and the `mysql.connector` library to establish connectivity between Python and the MySQL database. The database stores student information, administrator details, course information, enrollment records, and payment statuses.

The main objective of this project is to simplify course administration, reduce manual record-keeping, maintain student and course information systematically, and provide an easy-to-use platform for managing online course activities.
